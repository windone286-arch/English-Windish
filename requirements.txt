# ==========================================================================
# 运行时依赖
#
# 这里只放**启动 Web 服务真正需要**的包。
# 原理：部署时要在沙箱里现装一遍依赖，包越少装得越快、失败率越低。
# 开发工具和后续项目要用的包都挪到了 requirements-dev.txt。
# ==========================================================================

# HTTP 请求（调用大模型 API）
httpx>=0.27.0

# 环境变量加载（读取 .env）
python-dotenv>=1.0.1

# Web 框架
fastapi>=0.115.0

# ASGI 服务器
#
# 特意写成 uvicorn 而不是 uvicorn[standard]：
# standard 额外会拉 httptools / uvloop / watchfiles 这些**需要 C 编译器**
# 的扩展包，在没有编译环境的部署沙箱里很容易装不上。
# 纯 Python 实现（asyncio + h11）对本项目这种低并发场景完全够用。
uvicorn>=0.32.0

# 解析 multipart 表单
# 图片上传和 Form 字段都依赖它，缺了会直接报错
python-multipart>=0.0.12
